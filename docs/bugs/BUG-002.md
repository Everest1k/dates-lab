# BUG-002. Неверный день недели для дат в феврале

| Поле | Значение |
|------|----------|
| Модуль / функция | `weekday.DayOfWeek` |
| Статус | Открыта (Open) |
| Категория | Серьёзная (Major) |
| Тестовый случай | `TestDayOfWeek/29_февраля_2024_(четверг)` |
| Обнаружил | Романенко Кирилл Юрьевич, 09.10.2026 |
| Исполнитель | Маркевич Никита Сергеевич |

## Шаги воспроизведения
1. Клонировать репозиторий, перейти в корень проекта.
2. Выполнить: `go test -run 'TestDayOfWeek' -v ./weekday`
3. Тест вызывает `DayOfWeek(Date{2024, 2, 29})`.

**Полученный результат:** `2` (вторник)
**Ожидаемый результат:** `4` (четверг)

## Дополнительно
Вывод теста:

```
weekday_test.go:29: DayOfWeek({2024 2 29}) = 2, <nil>; ожидалось 4, nil
--- FAIL: TestDayOfWeek/29_февраля_2024_(четверг)
```

Даты в январе, апреле и октябре определяются верно. Предположительно, в формуле
Целлера февраль не переносится в конец предыдущего года (как месяц 14). Ошибка
затрагивает и другие функции для февральских дат: `IsWeekend({2024 2 3})`
(суббота) возвращает false, `CountWeekdayInMonth(2024, 2, Thursday)` — 4 вместо 5.
